# はじめに

このチュートリアルは、RoboCup Rescue Simulation（RCRS）で災害救助 agent を開発するための資料です。RCRS の基本概念、開発環境、Module 実装、ログによる検証を順に扱います。

## 対象読者

- RoboCup Rescue Simulation を初めて扱う方
- 災害救助エージェントの仕組みを理解し、戦略を実装したい方
- シミュレーション結果をログから分析し、改善を繰り返したい方

## 進め方

初めて RCRS を扱う場合は Tutorial 1 から順に進めてください。すでに環境構築が済んでいる場合は Tutorial 3 から始めることもできます。

:::note 対象バージョン

本資料は **2026年9月**時点で確認した RCRS Server と RCRS ADF の実装に基づきます。更新後は、チュートリアルと差異が生じる場合があります。

:::
